Privacy policy

Last updated 31 October 2026

This policy covers the India Treasury Brief website (https://indiatreasurybrief.github.io) and ITB Publisher, the private tool the show uses to publish its own content. Questions go to indiatreasurybrief@gmail.com.

This website

  • It sets no cookies, runs no analytics or advertising, has no forms, and loads nothing from other websites.
  • It's hosted on GitHub Pages. GitHub logs visitors' IP addresses for security, as described in the GitHub General Privacy Statement. We don't receive or use those logs.
  • Links to Spotify, Apple Podcasts, YouTube, Amazon Music, pod.link, X, LinkedIn and Instagram take you to those services, and their own privacy policies apply there.
  • If you email us, we use your message and address only to reply, and we don't share them.

ITB Publisher

ITB Publisher is a tool that only the show's operator uses, signed in to the show's own accounts. It isn't offered to anyone else and doesn't access anyone else's account. What it does.

Google and YouTube data

ITB Publisher uses YouTube API Services. By using it, the operator agrees to the YouTube Terms of Service, and Google's handling of the data is covered by the Google Privacy Policy.

  • What it accesses: the show's own YouTube channel. It uploads the show's episodes and Shorts, sets their titles, descriptions, thumbnails and subtitles, adds them to the show's playlist, and reads the channel's YouTube Analytics reports.
  • How it's used: only to publish the show's own content and to review how the show is doing.
  • Where it's stored: the sign-in token and any analytics reports are stored only on the operator's own computer. Nothing is stored on a server.
  • Sharing: the data isn't sold, shared or transferred to anyone, and isn't used for advertising.
  • Cookies: ITB Publisher runs on the operator's computer and doesn't place cookies on anyone's device.
  • Revoking access: access can be removed at any time from the Google security settings page. The stored token is deleted when access ends, and on request.

ITB Publisher's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Instagram and X

The tool can also post the show's own content to the show's own Instagram and X accounts through their official APIs, and read those posts' statistics. It handles only those accounts' access tokens and post details, stores them only on the operator's computer, and doesn't share them.

Children

The show is for working finance professionals and isn't directed at children.

Changes

If this policy changes, the new version will be posted here with a new date.
